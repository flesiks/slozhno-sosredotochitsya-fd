# Сложно сосредоточиться

Проектная работа по итогам 3-го спринта курса «Фронтенд-разработчик» в Яндекс Практикуме.

## Описание проекта

«Сложно сосредоточиться» — адаптивный сайт о проблемах концентрации внимания, причинах рассеянности и способах улучшить способность фокусироваться.

## Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Адаптивная вёрстка
- CSS-переменные
- Медиазапросы

## Функциональность

- Адаптация под мобильные устройства, планшеты и компьютеры.
- Светлая и тёмная темы оформления.
- Автоматическое определение системной темы.
- Сохранение выбранной темы.
- Адаптивная галерея изображений.
